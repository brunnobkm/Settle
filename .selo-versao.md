# O número da atualização

O selo do cabeçalho de `agentes-plataforma/index.html` mostra
`Atualização número 0.NNN`. O número é a contagem de commits do `main` que
tocaram o protótipo, e sobe um a cada publicação.

Para saber o próximo, antes de publicar:

```
git rev-list --count origin/main -- agentes-plataforma/ agentes/ agentes-rotinas/ assets/settle.css
```

Some 1 ao resultado (o commit que está sendo feito ainda não conta) e escreva
no selo com três casas: 151 vira `0.151`, 1024 vira `1.024`.
