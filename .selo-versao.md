# O número da atualização

O selo do cabeçalho de `settle-agentes/plataforma/index.html` mostra
`Atualização número N`. O número é a contagem de commits do `main` que
tocaram o protótipo, e sobe um a cada publicação. Sem zeros à esquerda e sem
separador: 152, não 0.152.

## Onde o número fica

A página agora é React: o `index.html` é gerado pelo build e não se edita à mão.
O número mora numa constante só, `ATUALIZACAO`, em
`settle-agentes/plataforma/app/versao.ts`. Para publicar:

1. Calcule o próximo número (abaixo).
2. Troque o valor de `ATUALIZACAO` em `app/versao.ts`.
3. Gere a página de novo: `cd react && npm run build -- settle-agentes/plataforma`.

Para saber o próximo, antes de publicar:

```
git rev-list --count origin/main -- settle-agentes/ agentes-plataforma/ agentes/ agentes-rotinas/ assets/settle.css
```

Some 1 ao resultado, porque o commit que está sendo feito ainda não conta.

Os caminhos antigos (`agentes-plataforma/`, `agentes/`, `agentes-rotinas/`) continuam no comando de
propósito: o histórico de antes da reorganização de 19/09/2026 está registrado neles.
