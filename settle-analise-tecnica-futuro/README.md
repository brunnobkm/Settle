# Settle · Análise Técnica — trilho FUTURO (protótipo)

> **Tela em React (desde 19/09/2026).** O código fica em `app/` (e nas subpáginas, em `<subpágina>/app/`);
> o `index.html` é gerado pelo build (`cd react && npm run build -- <pasta>`). Veja a seção "Stack" do `AGENTS.md` da raiz.
> O que este README descreve sobre arquivos HTML/JS/CSS se refere à versão anterior, que está no histórico do git.

Protótipo de demonstração para as **melhorias futuras / estratégicas** da Análise Técnica.
Parte da mesma base do protótipo principal e evolui as ideias de maior alcance:

- As 4 variáveis de decisão do cliente (governo pede · o que ofereço · upside/custo · risco concorrencial)
- Medidor de direcionamento de edital (marca / zona cinzenta / impugnação)
- Variável tempo / logística (prazo de entrega, disponibilidade de estoque)
- Terminologia (análise técnica → compatibilidade / aderência)

> Trilho "pontuais" (melhorias incrementais): https://brunnobkm.github.io/Settle/settle-analise-tecnica-melhorias/

Protótipo estático (HTML/CSS/JS), sem build.
